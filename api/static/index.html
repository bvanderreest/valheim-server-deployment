Checking for a server update…

Updating is not a background job. Here is exactly what update does to Lowood-AU:

  • Stops the server. Anyone playing is disconnected without warning.
  • Downloads and installs the new build. A few minutes.
  • Leaves the server stopped. It will not come back on its own — you start it.
  • The join code changes when you start it again. Tell the group.
  • Any mods installed may stop working with a major version.

What the numbers say

Each of these is computed from this window's log, not written in advance. Every verdict shows the figures it was reached from, and how.

Difficulty

Three layers, applied in this order at launch. A preset sets the baseline, modifiers override single categories, world keys are flags written into the save.

Preset

The baseline. Sets some or all five categories at once.

-preset

Modifiers

Override one category at a time. The ring is what the preset would give; the filled dot is what's in force.

-modifier
preset baseline in force override distance

World keys

Flags written into CrowsNest's save. Five of them cannot be undone by switching them off again — they are marked.

-setkey

Rates

Percent of vanilla. 100 is untouched; the bar shows how far you've moved. Half and double are the same distance from the centre.

-setkey <Key> <0–1000>

Settings

Server identity and networking. Most of these need a restart to take effect; the ones that don't are marked.

Logs

Live from /logs/stream. The server writes its own timestamps.
